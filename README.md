# 光数外贸ERP v0.5 - 連動易助版

外貿ERP演示，與易助系統連動，保留生產製造、庫存、財務等功能在易助側。

## 檔案說明

- index.html - 合併版（含完整功能）
- 外贸ERP演示_v0.5_单文件.html - 單檔版（供大陸客戶使用，離線可用）
- 1_shell.html ~ 5_app.js - 原始碼分段

## 使用方式

直接在瀏覽器中打開 index.html 或單檔版 HTML 檔案即可。

## 功能列表

- 銷售：客戶、報價、合同(PI)、跟單、樣品與借出、出運與單證
- 採購：物料需求與請購、採購單、供應商
- 倉庫與品質：收貨與檢驗、庫存
- 財務：應收與收款、應付與付款、匯率與結匯
- 易助連動：自動同步易助資料
