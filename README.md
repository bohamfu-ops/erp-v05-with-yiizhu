# 光数外贸 ERP 演示 - 连动易助版

外贸前端销售系统演示，与易助系统对接；生产、库存、财务的正式账仍在易助。

## 在线查看

启用 GitHub Pages 后访问：https://bohamfu-ops.github.io/erp-v05-with-yiizhu/

## 文件说明

- `index.html` - 完整演示（在线可直接打开）
- `外贸ERP演示_v0.5_单文件.html` - 单文件版，可离线直接双击打开
- `src/` - 原始码分段，便于维护

## 演示内容

- 需求确认、客户、报价、合同（PI）、跟单看板、样品、出运与单证、售后、业绩与提成
- 物料需求与请购、采购单、供应商
- 收货与检验、库存
- 工单、委外加工、产品与 BOM
- 应收与收款、应付与付款、汇率与结汇、出口退税、成本与利润、总账与关账
- 易助对接状态

数据均为虚构的演示数据。
